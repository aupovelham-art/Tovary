Зачем это нужно продавцу аксессуаров
Одна база вместо блокнота. Ищешь по модели — сразу видишь чехлы и остатки. Продажа за 10 секунд. График по часам показывает, когда лучше продаётся.
▾

Как продать за 10 секунд:

  1. Вкладка «Продажи»
  2. Категория или поиск по модели (Redmi 11)
  3. Кликни товар → количество → «Провести»

Почему удобнее блокнота:

  • Поиск по модели телефона
  • Остатки обновляются сами после продажи
  • Мин/макс цена для торга
  • График по часам за сегодня + история по дням
  • Всё офлайн, данные только у тебя
  • Быстрые +/− по остаткам
  • Отмена продажи с возвратом на склад
  • Фильтр «только заканчивается»
  • Экспорт базы
